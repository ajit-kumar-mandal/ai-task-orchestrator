## Project architecture
- Keep the GitHub Actions workflow and dependency-free Node task runner as portable source files; the runner accepts only repository-dispatch payloads, reads provider credentials from Actions secrets, and reports completion to the supplied HTTPS callback so users can push this repository and reuse it from another app.
